# Get your first gated pull request

## Before you start

- The Mac mini and the Spark on your tailnet, with Clyde installed on both.
- A Linear workspace where you are an admin.
- A GitHub repository with a `validate` script.

## Steps

1. In the desktop app, add the Mac mini as an environment. You see an empty
   Clyde.
2. Select **Connect Linear**. You see your Linear teams.
3. Add a project. You see its default workflow as a graph.
4. In Linear, delegate a small issue to Clyde. Clyde's first thought shows in
   the agent session, and the run shows in the app.
5. Watch the steps. Each gate shows its result as it finishes.

## Result

A pull request on GitHub, linked to the issue, and the issue in **In Review**.
Each gate's result is on the run's page in the app.
